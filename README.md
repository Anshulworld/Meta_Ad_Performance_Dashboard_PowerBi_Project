# Meta Ad Performance Dashboard - Power BI

## 📌 Project Overview
This repository contains a comprehensive **Meta Ad Performance Dashboard** built using Power BI. This project is designed to analyze, track, and visualize the effectiveness of advertising campaigns run across Meta's primary platforms: Facebook and Instagram. By consolidating complex ad data into an interactive dashboard, it provides clear, actionable insights to help optimize ad spend, improve audience targeting, and maximize Return on Ad Spend (ROAS).

## 🚀 Key Features
*   **Platform-Specific Views:** Dedicated dashboard pages for analyzing Facebook and Instagram ad performance independently, allowing for cross-platform comparison.
*   **Core KPI Tracking:** Real-time monitoring of essential advertising metrics including Impressions, Reach, Clicks, Click-Through Rate (CTR), Cost Per Click (CPC), and Total Conversions.
*   **Visual Demographics & Engagement:** Interactive charts that break down campaign performance by age, gender, location, and time periods to identify where and when ads perform best.
*   **Actionable Business Intelligence:** Empowers data-driven decision-making by quickly identifying top-performing ad creatives and underperforming campaigns.

## 📁 Repository Contents
*   **`Meta Ad Performance Dashboard.pbix`**: The main Power BI project file. It contains the complete data model, DAX measures, and all visualization layers.
*   **`Meta Ad Performance Dashboard.pbit`**: The Power BI template file. This allows you to generate a new report with the exact same visual structure and formatting while connecting it to your own Meta Ads dataset.
*   **`*.png`**: High-resolution screenshots of the dashboard for quick repository previews.

## 🛠️ Tools & Technologies Used
*   **Business Intelligence / Data Visualization:** Power BI (Desktop)
*   **Data Modeling:** Power Query & DAX (Data Analysis Expressions)
*   **Data Source Context:** Meta Ads Manager (Facebook & Instagram Campaign Data)

## 💡 How to Use This Project
1. Clone or download this repository to your local machine.
2. Open the **`Meta Ad Performance Dashboard.pbix`** file using **Power BI Desktop**.
3. Interact with the dashboard by clicking on different charts and slicers to see how the data filters dynamically.
4. *(Optional)* If you wish to plug in your own advertising data, you can open the `.pbit` file, update the data source credentials/path to point to your own dataset, and refresh the model.
